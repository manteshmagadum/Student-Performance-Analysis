# Student Performance Analysis Project

This project analyzes student academic performance using Python. It calculates total marks, percentages, and pass/fail status, and visualizes the results using graphical charts.

## Features
- Calculates total marks and percentages for students.
- Classifies pass/fail status based on performance.
- Visualizes results with Bar Charts.
- Exports processed data to a CSV report.

## Tech Stack
- Python
- Pandas
- Matplotlib
- Seaborn
